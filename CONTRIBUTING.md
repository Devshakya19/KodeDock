# 🛠️ Contributing to KodeDock

> [!NOTE]
> KodeDock is built by a small, focused team with a big mission: to make India's developer ecosystem more accessible by building the country's premier digital code marketplace.

Thank you for your interest in contributing to KodeDock! We are thrilled to welcome you to our growing community.

## 📜 License and Intellectual Property

> [!WARNING]
> KodeDock is **proprietary software**. External contributions are accepted only through an explicit written agreement with the KodeDock team.

To ensure the integrity of our platform and protect intellectual property, all contributions must go through our official channels. If you wish to contribute code, features, or bug fixes, you will need to sign a Contributor License Agreement (CLA) or establish a written agreement with us.

## 🤝 How to Get Involved

Even if direct code contribution requires an agreement, there are many ways you can help!

| Contribution Type | Description |
| --- | --- |
| **🐛 Bug Reports** | Help us identify issues by providing detailed bug reports. |
| **💡 Feature Requests** | Share your ideas to make KodeDock even better for the community. |
| **📖 Documentation** | Suggest improvements or report typos in our user guides and docs. |
| **🧑‍💻 Code** | Contribute to the core platform or integrations (reach out to us first). |

## 📬 Contact Information

If you are interested in contributing, partnering with us, or reporting issues, please reach out through the appropriate channel:

*   **📧 Team / General Inquiries**: [hello@kodedock.com](mailto:hello@kodedock.com)
*   **🔐 Security Issues**: [security@kodedock.com](mailto:security@kodedock.com)
*   **⚖️ Legal / Licensing / CLAs**: [legal@kodedock.com](mailto:legal@kodedock.com)

> [!IMPORTANT]
> Please do not report security vulnerabilities on public issues or forums. Email `security@kodedock.com` directly so we can resolve the issue safely.
