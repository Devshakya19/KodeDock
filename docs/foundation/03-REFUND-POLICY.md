# KodeDock — Refund & Cancellation Policy

> Clear, fair refund rules for digital code purchases.

---

**Effective Date:** August 1, 2026  
**Last Updated:** August 2, 2026

---

## 1. Overview

KodeDock sells **digital code assets** that are delivered instantly to your GitHub account. Due to the nature of digital goods, our refund policy is designed to be fair to both buyers and sellers while preventing abuse.

---

## 2. Digital Product Refunds

### 2.1 When Refunds Are Granted

You are eligible for a **full refund** if:

| Condition | Details |
|-----------|---------|
| **Product not delivered** | GitHub repo transfer failed and code was not received |
| **Product is non-functional** | Code does not run at all despite following documentation |
| **Product misrepresentation** | Product significantly differs from its description |
| **Malware/security issue** | Product contains malicious code (verified by our team) |
| **Duplicate charge** | You were charged twice for the same product |

### 2.2 When Refunds Are NOT Granted

Refunds will **not** be granted for:

| Condition | Reason |
|-----------|--------|
| **Change of mind** | Digital goods cannot be "returned" |
| **Already downloaded/used** | Code has been accessed and used |
| **Minor bugs** | Small issues that don't prevent core functionality |
| **Incompatibility** | Code works as described but doesn't fit your specific setup |
| **Skill level** | Code is too advanced for your expertise |
| **Buyer's failure to read** | Description clearly stated limitations |

### 2.3 Refund Window

| Purchase Type | Refund Window |
|---------------|---------------|
| Digital product | **Within 7 days** of purchase (during escrow period) |
| After escrow release | Refunds require seller dispute resolution |

## 3. How to Request a Refund

### Step-by-step process:

```
1. Contact seller first
   └── Use the product's discussion/support channel
   └── Sellers are encouraged to help resolve issues

2. If unresolved, raise a dispute
   └── Go to: Orders → Select Order → Raise Dispute
   └── Provide: Detailed description, evidence (screenshots/logs)

3. KodeDock mediation
   └── Our team reviews within 72 hours
   └── Decision: Full refund / Partial refund / No refund

4. Refund processing
   └── Refund to original payment method (Razorpay)
   └── Or credit to KodeDock wallet (instant)
```

### Refund Request Must Include:
- Order ID
- Product name
- Specific reason for refund
- Evidence (error logs, screenshots, screen recording)
- What you've tried to fix the issue

## 5. Seller Withdrawal Cancellation

### 5.1 Before Processing
- Sellers can cancel a withdrawal request **before it's processed**
- Cancellation returns funds to the available wallet balance instantly

### 5.2 After Processing
- Once funds are sent to the seller's bank/UPI, the transaction **cannot be reversed**
- Incorrect payout details provided by the seller are the seller's responsibility
- Sellers must verify their bank account number and UPI ID carefully before withdrawing

### 5.3 Minimum Withdrawal
- Minimum withdrawal: **₹500** (50,000 paise)
- Withdrawals below this amount cannot be processed

## 6. Escrow & Dispute Resolution

KodeDock's 7-day escrow system ensures fair resolution:

```
Day 0:    Purchase made → Seller earnings held in escrow
Day 0-7:  Buyer can raise a dispute if product is unsatisfactory
Day 7:    Escrow releases → Funds become available to seller

If dispute is raised:
├── Funds remain held until resolution
├── KodeDock team reviews evidence from both parties
├── Resolution within 72 hours
└── Outcome:
    ├── Buyer wins → Full refund to buyer, seller gets nothing
    ├── Seller wins → Funds released to seller
    └── Partial → Proportional split (rare, case-by-case)
```

## 8. Fraud & Abuse Prevention

To protect the Platform and honest sellers:

- **Chargeback abuse:** Filing false chargebacks after receiving working code will result in account suspension
- **Repeat refunders:** Accounts with excessive refund requests may face purchase restrictions
- **False disputes:** Raising disputes with fabricated evidence will result in account termination
- **Friend purchases:** Buying from friends/alt accounts to inflate sales is prohibited

We track refund patterns and investigate suspicious activity. Honest users have nothing to worry about — this section exists to protect sellers from fraud.

---

## 9. Subscription / Recurring Payments

KodeDock currently does **not** offer subscriptions or recurring payments. All transactions are one-time purchases. If subscriptions are introduced in the future, this section will be updated with cancellation terms.

---

## 10. Force Majeure

KodeDock is not liable for refund delays caused by:
- Payment gateway (Razorpay) outages
- Bank processing delays
- Natural disasters or government actions
- Internet infrastructure failures

In such cases, refunds will be processed as soon as normal operations resume.
